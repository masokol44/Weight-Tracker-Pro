# ⚖️ Weight Tracker Pro — следи за весом, экспортируй данные

> «Следи за килограммами — достигай целей»

**Weight Tracker Pro** — это набор консольных приложений для ведения дневника веса с возможностью экспорта данных в CSV и JSON.  
Программа позволяет добавлять записи с датой, весом, заметками, отслеживать прогресс, вычислять ИМТ и экспортировать данные для анализа.

## 🚀 Особенности
- 📝 Добавление записей: дата, вес (кг), заметки (опционально).
- 📋 Просмотр всех записей в таблице с цветовой индикацией.
- 📊 Статистика: средний вес, минимальный/максимальный вес, изменение за период, ИМТ.
- 📤 Экспорт данных в CSV и JSON (полный или по датам).
- 🔍 Фильтрация записей по дате.
- 🗑️ Удаление и редактирование записей.
- 💾 Автосохранение в JSON-файл (`weight_data.json`).
- 🎨 Цветной вывод в терминале.
- 📈 Расчёт тренда (рост/снижение веса).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python weight_tracker.py`              |
| Go         | стандартная библиотека               | `go run weight_tracker.go`              |
| JavaScript | Node.js, `fs`, `readline`            | `node weight_tracker.js`                |
| Java       | стандартная библиотека               | `javac weight_tracker.java && java weight_tracker` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `serde`, `serde_json`, `chrono`      | `cargo run`                             |
| Ruby       | `json`, `csv` (стандартные)          | `ruby weight_tracker.rb`                |
| PHP        | стандартная библиотека               | `php weight_tracker.php`                |
